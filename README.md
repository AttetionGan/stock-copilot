# Stock Copilot

个人美股观察与持仓管理工具：电脑查看完整信息，手机接收提醒并快速查看详情。

当前阶段：**M1 页面原型已通过用户验收（2026-10-18），快照标签 `v0.1.0-m1`；下一阶段为 M2 数据持久化与提醒状态机。** iPhone Safari 真机、真实行情、手机通知和部署仍需分别验证。

设计基线确认日期：2026-10-17。已明确四个核心模块、页面流程、版本边界和 12 项验收标准，并补齐行情过期、CSV 覆盖和通知失败处理规则。后续按 [开发路线](docs/ROADMAP.md) 推进。

原型包含总览、关注、持仓、提醒、设置与股票详情，支持会话内编辑区间、研究备注和提醒查看状态。低频显示偏好统一在设置页修改，不占用业务页首屏。持仓页提供随账户筛选变化的环形分布图，可切换是否包含现金。真实行情、持仓持久化、微信通知和 Mac mini 部署均未完成。M1 快照仅包含可公开源码、通用文档与人工构造演示截图，版本说明见 [CHANGELOG](CHANGELOG.md)。

## 运行 M1 原型

项目环境已安装时，可双击 [启动原型](scripts/start-demo.command)。在终端窗口按 Control+C 停止服务。该脚本会打开本机网页，服务仅监听 `127.0.0.1:8501`；这个地址不能直接从另一台设备访问。

要用 iPhone 验证：Mac 与手机连接同一 Wi-Fi，在 Mac 双击 [手机预览](scripts/start-mobile-demo.command)，然后在 iPhone Safari 打开终端显示的内网地址（端口 8502）。脚本仅绑定私有内网接口，电脑原有 8501 服务保持不变；仅用于可信局域网中的模拟数据。操作与排查见 [手机验证说明](docs/MOBILE_PREVIEW.md)。

首次安装需要 Python 3.12 或更高版本。在项目根目录运行：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python -m streamlit run app.py
```

`requirements.lock` 记录本次 Python 3.12 / macOS 环境验证的依赖版本，不包含本地安装路径或凭证；其他平台仍需验证安装兼容性。

原型只使用人工构造数据。编辑保留在当前浏览器连接会话中，刷新网页或重启服务会恢复演示数据；请勿录入真实信息。可在“设置”页展开“演示设置”切换 MU 的有效/过期/缺失报价，观察估值和提醒状态的变化。

导航进入“设置”页，可选“浅色模式／深色模式／跟随系统”和“绿涨红跌／红涨绿跌”，默认跟随系统、绿涨红跌；选择在当前设备会话内跨页保留，重置演示保留外观与涨跌配色。采用雾白/深蓝灰底色和靛蓝主色。已修复固定顶栏遮挡设置的问题，并实际验证桌面浅深模式、配色与币种切换；系统外观动态切换、图表及 iPhone Safari 真机仍待验证，微信内置浏览器单独检查。

“设置”页可切换资产显示币种 USD／CNY；总资产、现金、市值、总成本、盈亏及饼图金额同步换算，选择在当前会话跨页保留。人民币使用固定演示汇率 `1 USD = 7.20 CNY`，非实时，不含汇兑损益；报价、每股平均成本、观察区间及提醒价格仍显示 USD。原始持仓和现金保持美元，不支持录入人民币资产。

总览首区块为“以下股票已到重点观察区间”，去掉重复的“投资总览”大标题和说明行，用紧凑数量提示突出未查看事件。最多展示三条及全部提醒入口，其后为资产与三列关注股票；用途可标注买入观察／卖出观察／观察，由用户设置，不是系统交易建议。股票代码旁统一显示中文简称，详情保留英文名，持仓、提醒、添加选项和分布图同步使用中文名。持仓明细与分布图并排，关注页用于增删、筛选和配置，编辑表单折叠。总览与中文图表已做桌面/390px 宽度视觉检查，实际 iPhone Safari 仍待验证。

测试命令：`.venv/bin/python -m pytest -q`。本轮验证范围与限制见 [M1 验证记录](docs/M1_VALIDATION.md)。

## 目标使用场景

后续实现并部署后，Mac mini 在后台采集行情、检查用户配置的规则并保存事件。MacBook Air 和 iPhone 通过网页查看同一套记录；触发条件时，通过通知渠道提醒用户重新评估。

价格进入观察区间代表需要查看，不代表系统建议买入。

## v0.1 范围

四个核心模块的支持范围以 [PRD](docs/PRD.md) 为准：

| 模块 | 主要能力 |
|---|---|
| 行情观察 | 自定义关注列表、报价与近期走势、观察区间、手动研究背景 |
| 持仓管理 | 手动/CSV 录入、多账户汇总、成本/市值/未实现盈亏/占比、美元现金 |
| 价格提醒 | 同一标的多个区间、去重与冷却、历史记录、微信通知 |
| 投资面板 | 电脑和手机网页、资产摘要、股票与提醒详情、数据健康状态 |

优先验证微信通知，PWA 网页推送后置。Longbridge/IBKR 自动同步仅作可选探索，不是本版支持承诺。

不实现自动交易；不将运行时 LLM、自动券商同步、投资建议生成列为 v0.1 交付条件。

## 开发约定

- MacBook Air 开发和测试，Mac mini 部署和定时监控。
- 开发使用模拟数据；代码、真实数据与凭证分开存放。
- GitHub 仅保存代码、通用文档与人工构造样例；真实账户数据和本地配置不上传。参见 [上传边界](docs/REPOSITORY_POLICY.md)。
- 展示行情来源、行情时间、采集时间和数据状态。
- 浏览器关闭不能中断监控；推送服务接受请求不等于手机已收到。
- 部署、联网可用性和手机通知需实机验证，文档方案不能代替验收。
