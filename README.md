# Stock Copilot

个人美股观察与持仓管理工具：电脑查看完整信息，手机接收提醒并快速查看详情。

当前阶段：**v0.1 产品设计初稿已落盘；应用尚未实现，尚未部署或连接真实账户。**

## 使用场景

Mac mini 在后台采集行情、检查用户配置的规则并保存事件。MacBook Air 和 iPhone 通过网页查看同一套记录；触发条件时，通过通知渠道提醒用户重新评估。

价格进入观察区间代表需要查看，不代表系统建议买入。

## v0.1 范围

四个核心模块的支持范围以 [PRD](docs/PRD.md) 为准：

| 模块 | 主要能力 |
|---|---|
| 行情观察 | 自定义关注列表、报价与近期走势、观察区间、手动研究背景 |
| 持仓管理 | 手动/CSV 录入、多账户汇总、成本/市值/未实现盈亏/占比、美元现金 |
| 价格提醒 | 同一标的多个区间、去重与冷却、历史记录、微信通知 |
| 投资面板 | 电脑和手机网页、资产摘要、股票与提醒详情、数据健康状态 |

优先验证微信通知，PWA 网页推送后置。Longbridge/IBKR 自动同步仅作可选探索，不是本版支持承诺。

不实现自动交易；不将运行时 LLM、自动券商同步、投资建议生成列为 v0.1 交付条件。

## 开发约定

- MacBook Air 开发和测试，Mac mini 部署和定时监控。
- 开发使用模拟数据；代码、真实数据与凭证分开存放。
- GitHub 仅保存代码、通用文档与人工构造样例；真实账户数据和本地配置不上传。参见 [上传边界](docs/REPOSITORY_POLICY.md)。
- 展示行情来源、行情时间、采集时间和数据状态。
- 浏览器关闭不能中断监控；推送服务接受请求不等于手机已收到。
- 部署、联网可用性和手机通知需实机验证，文档方案不能代替验收。
