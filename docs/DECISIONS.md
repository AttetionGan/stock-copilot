2026-10-17：v0.1 产品设计已完成，M0 结束。以 [PRD](PRD.md) 作为开发范围与验收依据：四个核心模块、23 项功能要求、12 项验收标准；行情过期、CSV 覆盖和通知失败处理约定已补齐。

## 当前工作方案

产品范围以已确认的 PRD 为准。以下为开发起点，具体技术选型仍依据原型与接入验证修订，不代表每个依赖和服务均已验证。

| 方案 | 原因 |
|---|---|
| 网页为主界面，适配电脑与手机 | 对应查看与配置需求，减少客户端维护 |
| 浅色／深色／跟随系统三种外观 | 独立设置页切换，默认跟随系统；当前设备会话内跨页保留，手动模式覆盖系统偏好，不读取部署机外观 |
| mini 独立监控，Air 关闭不影响运行 | 与设备分工一致 |
| 微信通知先验证，PWA 后续增强 | 遵循手机偏好，控制第一版投入 |
| Python 单体、SQLite、独立后台任务 | 沿用初始设计，适合个人工具 |
| 手动/CSV 持仓先行 | 减少券商认证阻塞 |
| v0.1 只读，不包含交易执行与运行时 LLM | 保持原设计边界 |
| 先做模拟数据页面原型，再确定前端 | 避免仅根据框架方便程度决定手机体验 |

## 待验证，不阻塞进入开发

- Streamlit 已通过本机页面流程与手机尺寸检查；M1 页面原型已获用户确认，iPhone Safari 真机、访问认证和通知链接跳转仍待验证。
- 用户是否接受所选微信推送服务的注册/实名条件；实际额度、模板与投递效果。
- mini 的系统版本、电源配置、联网与远程连接是否可用。
- 无额外手机 App 的外网访问方案、费用、认证方式和国内网络表现。
- 行情源的权限、价格时效、交易日历与允许的使用方式。
- 行情源的最大报价年龄阈值与延迟信息；完成验证前仅用于展示，不启用价格提醒。

多原币资产、融资和空头持仓的本版边界已在 PRD 明确：不支持并在录入/导入时拒绝；美元资产的 USD/CNY 展示切换属于展示层功能，不改变此限制。

## 状态边界

2026-10-18 设置集中：用户指出每页顶部的低频设置占用首屏，改为独立设置页，桌面侧栏及手机底部导航增加入口；业务页移除外观、配色、币种和演示控制。修改仍立即作用于当前会话各页，临时控件清理不丢失已保存选择；长期持久化仍未实现。桌面总览在当前 1384×763 视口内可同时看到提醒、资产与五标的；390×844 下设置页及五项导航可操作，不等同于实际 iPhone 验收。

2026-10-18：对照初始设计补齐 [技术架构](ARCHITECTURE.md)，保留 Python 模块化单体、数据/界面分离、独立规则与适配器；明确 Pydantic、uv、真实行情和券商接口仍待采用/验证，不因整理文档扩充依赖。常开 mini 与微信手机通知采用后续决定；不恢复原设计中的仅桌面通知方案。总览去掉重复大标题和说明，首区块改名“以下股票已到重点观察区间”，缩小数量提示；六个演示标的统一中文名，英文名在详情保留。桌面与 390px 宽度视觉检查通过，本次 62 项自动检查通过；实际 iPhone Safari 与完整端到端监控仍未验收。

产品设计已完成；M1 模拟数据页面已实现，63 项自动检查通过。新版总览已实际验证桌面浅深外观、两种涨跌配色和 USD/CNY 切换；图表完整交互、系统动态切换和新版窄屏布局仍待检查，用户已确认 M1 页面原型通过，iPhone Safari 真机仍待验证。真实行情、数据持久化和手机通知尚未接入，没有部署 mini 或配置真实凭证。

外观三态选择已实现：初始浅深主题配置与统一调色板一致；运行时使用设备会话保存的选择及 CSS 变量覆盖卡片、控件、弹出层和图表文字/网格，“跟随系统”使用媒体查询。未修改进程级主题配置，避免影响其他访问设备。雾白/深蓝灰搭配靛蓝主色，绿/红用于涨跌与盈亏；原顶部控件和新版设置页均已实际验证，系统动态切换与微信内置浏览器行为仍待视觉验证。

数字显示统一为股价/总资产优先、持仓市值/盈亏次之、成本与说明为辅助；涨跌/盈亏可选绿涨红跌／红涨绿跌，默认绿涨红跌，并保留正负号。持仓收益率以成本为分母，报价涨跌以模拟前收盘为基准；过期/缺失数据使用中性提示。页面自动检查通过，实际字号与窄屏布局待视觉复核。

资产显示币种新增 USD/CNY 切换，当前会话内跨页保留；资产、现金、总成本、盈亏与饼图共用同一换算口径，美元底账不变，报价和区间仍为 USD。M1 使用明确标注的固定演示汇率 7.20，未接入真实汇率或汇兑损益计算；正式汇率来源与时间须在接入阶段验证。

界面默认紧凑，优先减少查看全局时的滚动：总览待查看提醒在前，突出数量、标的与用户标注的买入/卖出观察用途，其后为资产与三列关注股票；持仓明细与缩小的分布图并排，手机优先明细；详情编辑表单默认折叠。保留关键金额、区间和异常提示，去除重复标题和每张卡的大按钮。新版总览已完成桌面视觉检查；五标的一屏覆盖目标与新版窄屏显示仍待复核。

总览与关注分工进一步明确：总览保留行情摘要，关注页改为管理清单，支持标的增删、已配/未配区间筛选、启用数与关注理由填写状态，以及进入详情配置；不重复整套行情卡片。移除需确认并停用关联规则，保留持仓与历史。

新增显式的同 Wi-Fi 手机预览启动脚本，仅检测物理接口的私有内网 IPv4 并启动独立 8502 服务；默认电脑预览 8501 不变。已检查局域网启动与 HTTP 健康接口，测试临时服务已停止；iPhone Safari 真机操作仍待用户按手机验证文档完成，不等同于正式部署或访问认证已完成。
