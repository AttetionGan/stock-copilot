# iPhone 验证 M1 原型

## 最简启动路径

1. Mac 与 iPhone 连到同一普通 Wi-Fi，Mac 保持唤醒。
2. 在 Mac 双击 [手机预览启动脚本](../scripts/start-mobile-demo.command)，保留打开的终端窗口。
3. 在 iPhone Safari 打开窗口显示的地址，例如 `http://<Mac 的内网地址>:8502`。每次启动都以窗口显示的地址为准。

脚本读取当前物理网络接口，仅绑定私有内网 IPv4 地址，端口为 8502；电脑原有的 8501 服务不受影响。它不创建公网入口，也不修改防火墙或 CORS/XSRF 保护。当前无访问登录，仅在可信局域网中使用模拟数据，不录入真实持仓、凭证或备注。

`127.0.0.1` 在 iPhone 上指向 iPhone 自身，不能用于访问 Mac。停止预览时，在手机预览终端按 Control+C。

## 建议检查顺序

- 总览：检查资产摘要、五只演示股票、观察区间和底部导航；资产关系卡可在卡片内横向滑动，页面本身不应横向溢出。
- 外观：底部导航进入“设置”，依次选择“浅色模式”“深色模式”；再选择“跟随系统”，切换 iPhone 的浅/深外观并返回 Safari。检查背景、表单、弹出菜单、图表文字均清晰，手动选择不被系统切换覆盖。
- 币种：切换 CNY，确认总资产为 ¥121,284.00；演示汇率为固定 7.20，非实时。报价和观察区间仍显示 USD。
- 关注：管理页不再重复整套行情卡片。试用区间筛选、添加 AAPL、点击“配置”进入详情，以及需要确认的移除操作；移除保留持仓和历史提醒。
- 持仓：检查账户筛选、正负盈亏、分布图点触提示；手机先显示明细，再显示图表。
- 涨跌配色：在设置页切换“绿涨红跌／红涨绿跌”，检查报价涨跌和持仓盈亏同步换色，正负号、金额、区间状态与提醒强调色不变；总览待查看区间提醒应在资产之前，详情与全部提醒入口可操作。
- 演示设置：在设置页展开“演示设置”，切换报价过期/缺失，确认异常提示、待补全和暂停绘图；重置后恢复 USD/有效报价，保留外观与涨跌配色选择。
- Safari 检查完再试微信内置浏览器，不能将两者的结果互相替代。

两端运行相同代码，但 M1 的编辑数据和外观选择分别保存在各自浏览器连接会话中，不同步到另一设备；刷新或重启会恢复演示数据。连接上网页不代表真机验收完成，需按上述步骤实际检查。

## 无法连接时

确认脚本仍运行、地址没有输错、手机未使用蜂窝网络，以及 Mac 没有休眠。如果 macOS 询问是否允许 Python 的传入连接，允许当前测试进程；访客 Wi-Fi 或路由器的客户端隔离也可能阻止两台设备互访。不要为测试关闭整机防火墙或设置路由器端口转发。
